# 📝 Gestionnaire de tâches

Application web de gestion des tâches quotidiennes réalisée avec **Vue.js 3** et **Vite**.

## 📌 Présentation

Ce projet est une application **To-Do List** permettant à l'utilisateur de créer, modifier, supprimer et suivre ses tâches quotidiennes.

L'application possède une interface simple, moderne et responsive.

## 🚀 Technologies utilisées

- Vue.js 3
- Vite
- JavaScript
- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

## ✨ Fonctionnalités

- ➕ Ajouter une tâche
- ✏️ Modifier une tâche
- 🗑️ Supprimer une tâche
- ✅ Marquer une tâche comme terminée
- 🔄 Marquer une tâche comme non terminée
- 🔍 Rechercher une tâche
- 📋 Filtrer les tâches
- 🎯 Gérer les priorités
- 📊 Afficher les statistiques
- 📈 Afficher la progression
- 🌙 Mode sombre
- 💾 Sauvegarde avec localStorage
- ↩️ Annuler la suppression des tâches terminées

## 🎯 Filtres disponibles

- Toutes
- À faire
- Terminées
